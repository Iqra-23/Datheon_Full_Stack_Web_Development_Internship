# Datheon Full Stack Web Development Internship

This repository has the tasks I completed during my internship at Datheon.

## Tasks

| Task | Folder | Description |
| --- | --- | --- |
| Task 1 | `Task-1-Portfolio` | Responsive portfolio website |
| Task 2 | `Task-2-Task-Manager` | Task manager with CRUD and localStorage |
| Task 3 | `Task-3-Weather-App` | Weather forecast app with OpenWeatherMap API |

## Task 1: Portfolio Website

A responsive portfolio with dark and light mode, a project section and a contact form.
Live demo: https://iqra-23.github.io/portfolio/

## Task 2: Task Manager

A task manager with categories, due dates, filters, search and drag and drop. Tasks are saved in the browser with localStorage.

## Task 3: Weather App

A live weather app. Search any city to see the current weather and a 5-day forecast. The background changes with the weather. It uses the Fetch API, async / await and the OpenWeatherMap API. You need a free API key (see the README inside the task folder).

## How to run

Open the `index.html` file inside any task folder in your browser.
